개발하며 배운 것과 만든 것을 기록하려고 블로그를 열었습니다.

## 무엇을 쓰나요

- 개발 기록
- 만든 것에 대한 이야기
- 읽는 분과 나누고 싶은 생각

## 코드도 읽기 좋게

```ts
const greeting = (name: string) => `안녕하세요, ${name}`;
```

한 글에 여러 언어 버전이 있을 수 있어서, 위의 언어 링크로 바꿔 읽을 수 있습니다.
